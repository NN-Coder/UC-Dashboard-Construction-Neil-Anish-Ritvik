#mlh-data-sci

This repository hosts a data dashboard analyzing how socioeconomic status, measured by free or reduced-price meal percentages, correlates with unexpected University of California admission outcomes across high schools, comparing the standardized testing era from two thousand seventeen to two thousand nineteen against the test-blind era from two thousand twenty-two to two thousand twenty-five. Users can select specific campuses, including Berkeley, Davis, Irvine, Los Angeles, Merced, Riverside, San Diego, Santa Barbara, Santa Cruz, or view aggregated universitywide statistics. The application displays statistical metrics such as Pearson correlation coefficients, coefficients of determination, regression equations, and residual formulas alongside data caveats regarding redactions, grade point average saturation, and ecological fallacy considerations. The underlying data pipeline filters comma-separated values files using Python and Pandas libraries, dropping missing variables and categorizing academic terms into distinct policy eras while excluding transitional years. Built using Next and styled with Tailwind Cascading Style Sheets, the application is deployed on Vercel, providing an interactive interface for educational researchers and students to explore longitudinal public university admissions trends.
